1

一个大模型到底是什么

两个文件、一次有损压缩、一个说不清内部的产物

就是两个文件

他用 Llama 2 70B 开场，因为它是当时最强的开放权重模型：权重、架构、论文都公开了。不像 ChatGPT，你只能通过网页用。

训练 = 把互联网压缩进参数

运行很便宜，难在得到参数。他拿维基百科首页上一篇关于 Ruth Handler 的文章举例：要预测下一个词，就得知道她是谁、何时出生、做过什么。“预测下一个词”看似简单，却逼着网络把大量世界知识学进参数。

它会“做梦”

放开让它一直生成，它会“梦”出像网页的东西：一段 Java 代码、一个亚马逊商品页、一篇维基百科式的文章。商品页里的 ISBN 是编的，但格式对；它知道那个位置该出现什么样的东西。

我们知道怎么调它，却不知道它怎么工作

Transformer 的每一步运算都是清楚的，问题是上千亿参数散布在整个网络里。可解释性研究能弄懂一部分，但目前只能把它当作靠经验测量的产物：给输入、看输出、做评测。

预训练：先下载并处理互联网

数据从哪来，训练一次花多少

FineWeb：一个有代表性的预训练数据集

HuggingFace 整理的 FineWeb 详细公开了处理流程。他说 OpenAI、Anthropic、Google 内部都有类似的东西。目标是三件事：数量大、质量高、种类多。

训练一次 GPT-2，今天和 2019 年

GPT-2 是第一个“现代技术栈”齐全的模型，今天的模型只是每样都变大了。他在 8 块 H100 上复现时，屏幕上每一行是一次参数更新，盯着的只有 loss；每 20 步生成一段样本，从乱码慢慢变成有局部连贯的英文。

4

后训练：给 zip 贴上一张笑脸

对话怎么变成训练数据，你到底在和谁说话

算法不变，只换数据

后训练还是“预测下一个 token”，只是把互联网文档换成了对话。预训练可能要在几千台机器上跑大约三个月；后训练他举的例子是大约 3 小时，因为人工写的对话数据小得多（2023 年他说的量级是约 10 万条）。预训练管知识，后训练管格式和行为，他在 2023 年把后者叫 alignment。

谁在写这些对话

公司写标注规范，核心是三个词：helpful、truthful、harmless，完整版本可能有几百页。

你在和谁说话

他的说法是：ChatGPT 的回答是一个“人类标注员”的即时统计模拟。这个标注员通常是相当专业的人，按公司的规范作答。比如问“巴黎最值得去的五个景点”：如果这个问题恰好在后训练数据里，你得到的大概就是当时那位标注员上网查了 20 分钟后写下的清单；如果不在，就是预训练知识和标注员风格的混合。

“你是谁？”是个没意义的问题

模型没有持续存在的自我：每次对话启动、处理 token、关闭，下次从零开始。它说自己是谁，要么是后训练数据里硬编码的，比如 AI2 的 OLMo 在约 100 万条对话里放了 240 条“我是 OLMo，由艾伦人工智能研究所开发”；要么写在对话开头的系统消息里。什么都不做的话，它只会给出统计上最像的猜测：老模型 Falcon 说自己是 OpenAI 基于 GPT-3 做的。他认为这不能说明它用了 OpenAI 的数据，只是互联网上关于 ChatGPT 和 OpenAI 的文字太多了。

强化学习与思考模型

第三个训练阶段，也是 2025 年最新的前沿

上学的类比

为什么不能只靠人写解法

人写的解法对人来说自然，对模型却未必：有的步骤对它太简单，浪费 token；有的跳得太快，它跟不上。人和模型的“认知”不同，我们没法替它写出最适合它的 token 序列。模仿只能用来初始化，之后要让它自己在试错中找到对它管用的解法。做法很简单：对同一个提示采样大量解法（实践中可能上千甚至上百万个），鼓励那些得出正确答案的。

DeepSeek-R1：思考是自己长出来的

预训练和 SFT 各家都做了很多年，RL 阶段还很早期、细节很多。DeepSeek-R1 的论文公开讲了在数学题上做 RL 的效果：准确率上升的同时，平均回答长度也在上升。看那些长回答，模型学会了换个角度重来、回头检查、“等一下，我再算一遍”。论文里有一句模型自己写出的话：

“Wait, wait. Wait. That's an aha moment I can flag here.”

没有人告诉它要这样做，只给了正确答案。这类模型叫思考模型或推理模型。他提醒 DeepSeek 是中国公司，介意的话可以在 together.ai 这类推理服务商上用同一个开放权重模型。

AlphaGo 早就演示过一次

两个讲座在这里接上了。2023 年他说，LLM 还停留在 AlphaGo 的第一阶段（模仿人类），难点是开放的语言任务没有一个简单、便宜的奖励函数，也许只在窄领域能做到自我提升。到 2025 年，在数学、代码这类答案可验证的领域，这一步已经实现了。

2023 年他举的例子是 Greg Brockman 拿铅笔画了一个笑话网站的草图，ChatGPT 看图写出了能用的 HTML 和 JavaScript。2025 年他解释了原理：

System 2、自我改进、定制化

2023 年他列的三个方向：让模型能“想得更久”，他的说法是把时间换成准确率，像搭一棵思考树那样反复推敲；自我改进（上面 AlphaGo 那一节）；定制化，比如当时刚发布的 GPTs 商店，可以加自定义指令、上传文件做检索增强生成。前两个方向在 2025 年变成了思考模型。

LLM OS

生态也对得上：桌面系统有 Windows、macOS 这些闭源系统，也有基于 Linux 的大量开源系统；LLM 这边有 GPT、Claude、Bard 这些闭源模型，也有当时主要基于 Llama 的开源生态。

2025 年他预告的方向

  • 多模态会很快成为默认：原生地听、说、看、画。
  • 智能体：能连贯地执行很长时间的任务，人定期检查进度。他说会出现类似工厂里“人机比”的“人和智能体的比例”。
  • 无处不在、不再显眼：集成进各种工具里。
  • 操作电脑：比如 OpenAI 的 Operator，能替你点鼠标、敲键盘。

他建议这样想：ChatGPT 是一个大约 1 TB 量级的有损 zip，里面是几个月甚至一年前的互联网（所以有知识截止日期），后训练给它贴了一张笑脸，让它扮演助手。它本身是封闭的、惰性的，不联网、不会运行代码，除非给它工具。
